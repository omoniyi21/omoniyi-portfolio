# Omoniyi Stardust Creature Asset Kit

A tiny explorer made of stardust and curiosity. This kit keeps the approved character direction: hand-drawn, imperfect, warm, and expressive—always a companion, never a corporate mascot.

## What is included

Each illustration is available as:

- Editable, infinitely scalable SVG
- Transparent PNG at 512 px
- Transparent PNG at 1024 px

| Asset | Suggested portfolio placement |
| --- | --- |
| `stardust-mark` | Logo medallion, favicon source, loading mark |
| `hero-explorer` | Homepage hero, positioned near the headline or lower-right edge |
| `nav-peek` | Peeking over the navigation or a section divider |
| `project-curious` | Project-card corner or case-study intro |
| `observations-telescope` | Observations section |
| `insight-point` | Process, research findings, or case-study insight callout |

| `possibilities-flag` | Outcome, impact, or “what’s next” section |

## React use

```jsx
<img
  src="/assets/stardust/svg/hero-explorer.svg"
  alt="Stardust Creature exploring a trail of ideas"
  className="stardust stardust--float"
/>
```

Copy `css/stardust-motion.css` into your styles and respect reduced-motion preferences. The SVGs already contain accessible titles and descriptions, but when used through an `<img>` tag, the page-level `alt` text is what visitors receive.

## Sizing guidance

- Hero: 280–420 px wide
- Section companion: 140–240 px wide
- Project-card corner: 90–150 px wide
- Navigation peek: 90–130 px wide
- Footer scene: 320–520 px wide

Keep generous breathing room around the creature. Let it quietly notice the interface rather than dominate it.
